# Icons for Tab Renamer Extension

This folder should contain the following icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using any image editor. Here are some suggestions:

### Design Guidelines
- Use a simple, recognizable symbol (e.g., a pencil, edit icon, or "Ab" text)
- Use clear, high-contrast colors
- Ensure the icon is readable at 16x16 pixels
- Consider using a consistent color scheme

### Quick Solutions
1. **Use an online icon generator** like favicon.io or iconifier.net
2. **Use free icon resources** like Feather Icons, Heroicons, or Material Icons
3. **Create simple text-based icons** using tools like Canva or GIMP

### Example Icon Ideas
- ✏️ Pencil icon (editing/writing theme)
- 🏷️ Tag icon (labeling theme)
- "Ab" text with an edit symbol
- A tab shape with a pencil overlay

## Temporary Workaround

The extension will work without these icons, but Chrome will show default placeholder icons. For the best user experience, please add the icon files before installing the extension.

## File Requirements
- Format: PNG
- Transparent background recommended
- Square aspect ratio (1:1)
- Clean, scalable design
