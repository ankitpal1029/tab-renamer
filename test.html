📋 Extension Installation Checklist

  • Extension is loaded in Chrome (chrome://extensions/)
  • Developer mode is enabled
  • Tab Renamer appears in extensions list
  • Extension icon is visible in toolbar (or extensions menu)
  • No error messages in the extensions page

🖱️ Right-Click Context Menu Test

Instructions:
  1. Right-click anywhere on this page
  2. Look for "Rename Tab" in the context menu
  3. Click "Rename Tab"
  4. Enter a custom name (e.g., "My Test Tab")
  5. Press Enter or click "Rename"
  6. Check if the browser tab title changed
✅ Expected Result: The tab title should change to your custom name

🔧 Extension Popup Test

Instructions:
  1. Click the Tab Renamer icon in the Chrome toolbar
  2. The popup should show the current tab title
  3. Click "Rename This Tab" button
  4. Enter a different custom name
  5. Press Enter or click "Rename"
  6. Verify the tab title updates
✅ Expected Result: The popup should close and tab title should update

🔄 Reset Functionality Test

Instructions:
  1. First, rename this tab using either method above
  2. Right-click and select "Rename Tab" again
  3. Click "Reset to Original" button
  4. Verify the tab title returns to "Tab Renamer Test Page"
✅ Expected Result: Tab title should reset to the original page title

🐛 Troubleshooting

If the context menu doesn't appear:

  • Refresh this page and try again
  • Check chrome://extensions/ for error messages
  • Make sure the extension is enabled
  • Try reloading the extension (click refresh icon)

If the dialog doesn't show:

  • Open Developer Tools (F12) and check for JavaScript errors
  • Try disabling other extensions temporarily
  • Check if the content script is injected properly

If tab names don't persist:

  • This is expected across browser restarts (names are stored in memory)
  • Names should persist within the same tab during navigation
  • Check the background script console for errors
